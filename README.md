# TaskFlow - To-Do List & Produktivitas

Aplikasi manajemen tugas (to-do list) dan produktivitas modern dengan tampilan responsif, kalender interaktif, analitik produktivitas, serta dukungan ekspor laporan.

## Cara Menjalankan Secara Lokal

**Prasyarat:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Jalankan aplikasi:
   ```bash
   npm run dev
   ```

3. Buka browser di `http://localhost:3000`
